# PIN RATIONALE (do not relax without re-verifying):
#   transformers <4.45  -> unconstrained resolves to 5.x, which breaks mlflow 2.16.2's
#                          `mlflow.transformers` flavor (Task 2 registration fails).
#   torch ==2.8.0       -> matches the CPU wheel installed from download.pytorch.org.
#   torchvision REMOVED -> nothing imports it, and on linux/arm64 the +cpu cp312 wheels
#                          start at 0.25.0 (needs torch 2.10), so it cannot co-resolve.
#   fasttext   ==0.9.3  -> REQUIRED, and there is no way around it: deepchecks 0.19.1's
#                          calculate_builtin_properties() calls get_fasttext_model()
#                          UNCONDITIONALLY (text_properties.py, before any property
#                          filtering), so neither include_properties=["Sentiment"] nor
#                          ignore_non_english_samples_for_english_properties=False avoids it.
#                          PyPI has only one prebuilt wheel (cp39-macosx_14_0_arm64), but the
#                          sdist compiles cleanly on py3.12 given a C++ toolchain --
#                          docker/Dockerfile.tooling installs build-essential for exactly this.
#                          Deliberately absent from requirements-api.txt: the serving path
#                          never imports deepchecks.
#   nltk >=3.9.1        -> deepchecks probes for the `punkt_tab` resource, which first
#                          ships in 3.9.1, but deepchecks itself only requires >=3.8.1.
